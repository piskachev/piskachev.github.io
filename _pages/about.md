I am an Applied Scientist at Amazon Web Services, based in New York, USA. My work focuses on building automated reasoning tools that make systems secure at scale. Currently, I am developing deterministic techniques that help security reviews keep up with the accelerating pace of software development driven by generative AI. 

My recent work was in the data protection space, where I developed techniques for detecting and protecting sensitive data in code, logs, documents, and other unstructured data. Before that, I worked on program analysis, specifically a taint analysis framework that identifies security and privacy vulnerabilities in source code. This analysis was available to external customers through Amazon CodeGuru. The technical approach is described in our paper [Compositional Taint Analysis for Enforcing Security and Privacy Policies at Scale](https://www.amazon.science/publications/compositional-taint-analysis-for-enforcing-security-policies-at-scale).

I hold a PhD from Paderborn University, supervised by Prof. Dr. [Eric Bodden](https://www.bodden.de/). In my [PhD thesis](https://digital.ub.uni-paderborn.de/doi/10.17619/UNIPB/1-1665), I developed techniques that bring taint analysis for detecting security vulnerabilities closer to software developers. During my doctoral studies, I received a research grant through the Software Campus program, funded by the German Federal Ministry of Education and Research, for the project [SecuCheck](https://secucheck.github.io/).

**Research Interests**

* Program analysis
* Application security
* Privacy engineering
* Responsible AI
* Empirical software engineering
